I’m not a DevOps Engineer, but I believe it’s quite important for Software Engineers to understand DevOps. I’ve often heard about software services running into their first production-readiness issues only when they try to deploy to production. That’s why I think developers should know how the deployment process actually works.

Besides, I find it really interesting to automate an entire workflow. It’s fascinating to push changes and immediately see how the code performs — whether something breaks, how the test coverage looks, or if the application performs better or worse. In the end, you get an image that you can deploy — or even automate that part of the process as well.
