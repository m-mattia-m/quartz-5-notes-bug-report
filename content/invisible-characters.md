If you need a invisible character to force a space where spaces aren't allowed, you can just use the Unicode `U+2800` which is this one here `⠀`. You can copy it from this website if it doesn't work via Obsidian. [benz-reichenauer.de](https://benz-reichenauer.de/smart-social-stories/unsichtbares-zeichen-leerzeichen-kopieren)
