> I didn't uses/tested them but I saw them and want to have a note for a time I might need them to test my own software/tools/websites.

- [shodan.io](https://shodan.io) | [censys.com](https://censys.com)
  - find open servers and ports
- [hunter.io](https://hunter.io)
  - collects email addresses of a domain
- [urlscan.io](https://urlscan.io)
  - analyses a complete website
- [grep.app](https://grep.app)
  - analyses source code
- [intelx.io](https://intelx.io)
  - combines OSINT data
- [wigle.net](https://wigle.net)
  - maps WLAN networks
- [fullhunt.io](https://fullhunt.io)
  - scans your area of attack
- [vulners.com](https://vulners.com)
  - shows known vulnerabilities
- [viz.greynoise.io](https://viz.greynoise.io)
  provides threat intelligence
- Subdomain finders:
  - [osint.sh](https://osint.sh/subdomain/)
  - [whoisxmlapi.com](https://subdomains.whoisxmlapi.com/)
  - [merklemap.com](https://www.merklemap.com/)
  - [subdomainfinder.c99.nl](https://subdomainfinder.c99.nl/)
  - [pentest-tools.com](https://pentest-tools.com/information-gathering/find-subdomains-of-domain)
  - [seranking.com](https://seranking.com/de/kostenlose-tools/subdomain-check.html)
- [cyberscan.io](cyberscan.io/domains)
  - application to test public [[Domains]]/[[WebApps]]/[[API]]s
