# How do I navigate on this site?

I'm using a tag-based structure in my Obsidian Vault, and therefore the Quartz navigation might seem a bit messy at first. So what is tag-based navigation? In my understanding (or at least how I use it), you assign different tags to your notes based on their content.

For example, this site is related to Obsidian and therefore has the tag `Obsidian`. To create a clearer structure, you can define a hierarchy using slashes, like `root/child`. In my case, Obsidian belongs to the category `NoteTaking` (which also includes tools like Notion, Markdown, etc.). When you combine them, you get something like `NoteTaking/Obsidian`, which defines the tag path.

Unfortunately, Quartz does not fully support this kind of hierarchical tag structure. Therefore, you have to navigate via the [[tags]] page, use the Graph view, or search using the search bar.

Long story short: in my Obsidian Vault, I usually navigate with `CMD` + `F` to search within content, or `CMD` + `O` to search for file titles. Alternatively, you can use the Graph view to explore and navigate.
